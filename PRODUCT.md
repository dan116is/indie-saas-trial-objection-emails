| Signal | Email | Skip if |
|---|---|---|
| Stalled after signup, no activation | O1 nudge to one action | They asked to stop |
| Said too expensive | O2 value + cheaper plan if you have one | You have only one price and will not bend |
| Said no time | O3 10-minute path |  |
| Said need approval | O4 forwardable blurb |  |
| Said missing feature | O5 honest roadmap / workaround | You plan to fake the feature |
| Soft no / silence late trial | O6 last | Anything but silence |

**O1**

```
{{name}} — you started a trial of {{product}}. The one action that unlocks it: {{one_action}} (<10 min). Reply if stuck.
```

```

```

**O3**

```

```

**O4**


**O5**

```

```

**O6 last**

```

```
